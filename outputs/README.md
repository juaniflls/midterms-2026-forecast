# Generated outputs

This directory contains the complete audited output family generated by the v26 notebook. The canonical presentation and runtime files are:

- `Election_Model_Final_Report_v26.xlsx`: consolidated workbook consumed by Dash;
- `Model_Sensitivity_Audit_v26.xlsx`: one-at-a-time sensitivity audit;
- `scenario_state_engine_v26.py`: generated read-only Scenario Lab runtime;
- `Block6_Final_Uncertainty_Report.xlsx`: uncertainty report; and
- the block-level workbooks supporting national validation, constrained predictions, chamber forecasts, state races, simulations, stability, and diagnostics.

The numbered `v12` suffix on many block-level workbooks belongs to the internal block schema and does not indicate that the repository is running model v12. The current model release is v26 and the current Dash presentation is v26.1.

Older consolidated reports and scenario runtimes are intentionally excluded from the current branch so that Dash cannot silently select a stale snapshot. Historical releases remain recoverable through Git history and tagged releases.
