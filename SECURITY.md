# Security Policy

## Supported version

Security and reproducibility fixes are applied to the latest public release and the default branch.

## Reporting a vulnerability

Please do not publish credentials, personal information, malicious payloads, or a detailed exploit in a public issue. Use GitHub's private vulnerability-reporting or Security Advisory flow if enabled for the repository. For non-sensitive reproducibility defects, use the bug-report template.

This project processes local spreadsheets, notebooks, HTML, and geospatial archives. Review third-party files before execution and install dependencies inside an isolated environment.
