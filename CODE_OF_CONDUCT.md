# Code of Conduct

This repository is intended to support serious, evidence-based collaboration across political science, statistics, data science, software engineering, and electoral analysis.

## Expected behavior

- Discuss evidence, assumptions, and methods with precision and respect.
- Distinguish technical criticism from personal criticism.
- Be transparent about uncertainty, data limitations, and conflicts of interest.
- Credit sources and contributors clearly.
- Protect private or sensitive information.
- Make room for questions from contributors with different disciplinary backgrounds.

## Unacceptable behavior

Harassment, intimidation, discriminatory language, personal attacks, deliberate misrepresentation of evidence, doxxing, spam, and partisan abuse are not acceptable.

## Enforcement

Repository maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary. Concerns should be reported privately through GitHub's repository contact or security-reporting mechanisms when possible.
